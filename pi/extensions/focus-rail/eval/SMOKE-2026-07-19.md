# Initial A/B smoke test

## Setup

- Runtime: two fresh Pi sessions in Herdr sibling panes
- Model: `openai-codex/gpt-5.6-sol`, thinking `high`
- Baseline: `PI_FOCUS_RAIL=off`
- Treatment: `PI_FOCUS_RAIL=blend`
- Prompt: `autonomous-work` from `scenarios.ts`

## Observation

Both final answers were concise and usable. Neither exposed the policy or manufactured a user handoff after the hypothetical tests passed.

The baseline session attempted repository discovery, called CodeGraph, fell back to broad search, and read Focus Rail files before answering. Its footer reported roughly 32k input tokens. The treatment answered directly without tool calls and reported roughly 11k input tokens.

This is encouraging for the "do not narrate or perform irrelevant tool work" behavior, but it is not conclusive: CodeGraph startup failed only in the baseline because another process held the index lock. Repeat matched trials before attributing the token difference to the policy.

## Next experiment

Run every scenario at least three times per mode, alternating launch order. Record final text, tool-call count, input/output tokens, latency, policy leakage, unnecessary handoff, completeness, and safety outcome.
